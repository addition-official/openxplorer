QUESTION: The brief says Windows 11's Replace sends the replaced item to the Recycle Bin. I could not confirm that. Microsoft's IFileOperation page documents FOFX_RECYCLEONDELETE (Windows 8) only for deletes, and a Microsoft Q&A answer and a Directory Opus forum thread say Explorer's Replace overwrites the old file permanently. Neither is official documentation. This branch keeps #248's existing design, where Replace sends the replaced item to the Recycle Bin, so a restore never overwrites. The first twin therefore goes back to the Recycle Bin. Should Replace overwrite permanently instead, as those sources describe?
