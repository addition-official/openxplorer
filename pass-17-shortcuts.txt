1. Naming: in Documents, with View > Show > File name extensions OFF, right-click song.mp3 > Show more options > Create shortcut. Look for: is it named "song.mp3 - Shortcut" or "song - Shortcut"? Repeat with extensions ON. Do it again: is the second "song.mp3 - Shortcut (2)"?
2. After Create shortcut: is the new shortcut selected, and is its name in rename mode or not?
3. Create shortcut where Windows cannot write (right-click a file in C:\Windows > Show more options > Create shortcut). Look for: the window title, the exact text ("Windows can't create a shortcut here. Do you want the shortcut to be placed on the desktop instead?"?), and the buttons (Yes / No?).
4. Problem with Shortcut: make a shortcut to a text file on the Desktop, delete the file, double-click the shortcut. Look for: the title, the exact text, the buttons (Yes / No? Delete / Cancel?), which button is the default (Enter), and whether Y and N alone answer it. Does Yes put the shortcut in the Recycle Bin? Does Windows first show "Missing Shortcut — Windows is searching for…"?
5. Unavailable drive: make a shortcut to a folder on a USB stick, eject the stick, double-click the shortcut. Look for: the title and buttons of "The drive or network connection that the shortcut … refers to is unavailable…", and whether the name in it ends in ".lnk".
6. Folder shortcut: double-click "Projects - Shortcut" on the Desktop. Look for: does the address bar show the target folder's own path (C:\Users\<you>\Projects), and does Up go to its parent rather than to the Desktop?
7. New > Shortcut wizard: page 1 and page 2 headings ("What item would you like to create a shortcut for?", "What would you like to name the shortcut?"), the button labels and their order on each page (Back, Next, Finish, Cancel), and the name page 2 proposes for: C:\Users\<you>\Music\song.mp3, a folder, https://example.org, \\server\share. What does Next say for a path that does not exist (exact text)?
8. Sorting: on the Desktop with a folder, a file and a shortcut to a folder, View > Sort by > Name. Look for: does the folder shortcut sort among the folders or among the files?
9. Columns: in Details view, what do Size and Date modified show for a shortcut to a 20 MB video: the shortcut's own (1-2 KB, when it was made) or the video's?
10. Properties of a shortcut: the General tab's icon (the target's icon with the arrow?) and its "Type of file:" text; the Shortcut tab's fields in order.
11. A shortcut (.lnk) or Internet shortcut (.url) downloaded in a ZIP from the web and extracted: what warning, if any, appears when it is opened?
12. Rename a shortcut in place: is the whole name selected, and typing "song.mp3" keeps .lnk hidden (it stays a shortcut)?
