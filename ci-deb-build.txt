WHAT IT DOES
- Trigger: a push to test-combined-* (not *-deb) builds the pushed commit. "Run workflow" (workflow_dispatch, input "ref") builds that branch's tip.
- build job (ubuntu:24.04 container, contents: read), the release's Debian leg reused step by step:
  1. Name the package: test-combined-NN gives openxplorer_<version>+testNN_all.deb (a hyphen in NN becomes a dot, so test-combined-ci-check gives 2.0.23+testci.check).
  2. Author check: every commit on top of AKolenda/openxplorer main must be authored by addition-official (with its noreply address) or AKolenda. Offending commits are listed by hash only.
  3. sh native/packaging/ci/prepare-container.sh debian (the same apt packages; zstd added only for the cache action).
  4. Restore the cache: builder's ~/.cargo/registry index and cache, ~/.cargo/git/db, native/target.
  5. Rust 1.92.0 with rustup as builder (install-rust.sh's toolchain; the extra stable toolchain the Arch package needs is left out).
  6. runuser -u builder -- sh native/packaging/ci/build-package.sh deb io.winspace.Development (build_deb.py and verify_deb.py, cargo build --release --locked, no cargo clean).
  7. Save the cache, minus the ox-core and ox-app artifacts, which a fresh checkout makes Cargo rebuild anyway.
  8. Set Version to <version>+testNN with dpkg-deb -R and rebuild with build_deb.py's flags; the step fails if the file list, modes, times or any other control field differ from the verified package.
  9. Checks: dpkg-deb -c lists no .ttf/.otf/.ttc/.fon/.woff/.woff2/.ico/.cur/.exe/.dll/.mun/.res; no file starts with a PE, TrueType, OpenType, collection or WOFF header; every postinst line that writes the polkit rule sits inside the test that /var/lib/openxplorer/install-updates-without-password is not "off".
  10. Upload the deb as the artifact "test-deb".
- publish job (contents: write): force-pushes claude/test-combined-NN-deb as one orphan commit holding only the deb, author and committer addition-official, message like today's plus the run URL.
- status job (contents: write): updates test-combined-NN.txt on this branch through the contents API, as addition-official. On success the leading block becomes STATUS: DONE (deb ready; built by GitHub Actions), HEAD, DEB, SHA256 and RUN; on failure STATUS: FAILED with the step, RUN and the last 30 lines of that step's log. Everything a session wrote below that block is kept.
- The status files live at the root of this branch, like every other one, so "status/test-combined-NN.txt" is written as test-combined-NN.txt here.

CACHE
- GitHub only lets a branch restore its own caches and the default branch's. A new test-combined-NN branch therefore starts from the main cache, which only a "Run workflow" run (it runs on main) saves. After enabling Actions, do one "Run workflow" with any test branch to seed it, and again whenever Cargo.lock changes a lot. A second push to the same branch uses that branch's own cache too.

HOW TO ENABLE (on github.com, signed in as addition-official)
1. Open https://github.com/addition-official/openxplorer and click the "Actions" tab.
2. Click the green button "I understand my workflows, go ahead and enable them".
3. Settings tab > left sidebar "Actions" > "General". Under "Actions permissions" choose "Allow all actions and reusable workflows" (it needs actions/checkout, actions/cache and the artifact actions). Click Save. "Workflow permissions" can stay at "Read repository contents and packages permissions": the workflow asks for contents: write itself.
4. Optional but recommended: back on the Actions tab, in the left list click "Build, release and deploy", then the "..." button at the top right, then "Disable workflow". Do the same for "Native Rust checks" and "Native distribution packages" (and, if a sync brings them to main, "Repository checks", "Capture sandbox checks", "Flatpak repository", "Retry release and deploy" and "Pull request title"). Leave "Fork test deb" enabled.
5. To seed the cache and see a first run: Actions > "Fork test deb" > "Run workflow", keep "Use workflow from: main", type test-combined-ci-check in "ref", click "Run workflow". It should write claude/test-combined-ci-check-deb and test-combined-ci-check.txt here.
