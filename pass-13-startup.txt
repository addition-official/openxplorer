VM CHECK (Windows 11 VM; none of these is on a Microsoft page)
1. How fast File Explorer opens
   Steps: restart Windows, sign in and wait a minute. Start a screen recording (Win+Alt+R with Xbox Game Bar, or a phone at 60 fps). Press Win+E. Then close the window, wait 10 s, press Win+E again. Do it three times.
   Look for: the time from the key press to the window drawn, and to the file list (Home) filled. Is the first window after sign-in slower than the later ones?
2. Another window while one is open
   Steps: with one File Explorer window open on Documents, press Win+E, then Ctrl+N in the window.
   Look for: the time until the new window shows its files. Where does Ctrl+N open (the same folder or Home)?
3. Memory comes back down
   Steps: Task Manager > Details, add the column "Memory (private working set)". Note explorer.exe's value with no File Explorer window open. Open Pictures with about 2,000 photos, View > Large icons, press End and wait until the thumbnails are drawn. Note the value. Close the window, wait one minute, note it again.
   Look for: does explorer.exe go back near the first value, or stay high?
4. Thumbnail helper processes
   Steps: in Task Manager > Details while scrolling the 2,000 photos in Large icons, sort by name and look for dllhost.exe ("COM Surrogate") processes appearing. Leave the folder and watch them.
   Look for: how many appear, their memory, and how long after leaving the folder they end (this app stops its decoders after 30 s without a picture).
5. Gallery
   Steps: open Gallery with the same photos, scroll to the bottom, note explorer.exe's memory; open Home instead, wait a minute, note it again.
   Look for: whether memory drops when Gallery is left.
6. Twenty tabs
   Steps: in one window press Ctrl+T 19 times, note explorer.exe's memory and thread count (Details > add the Threads column); close 19 tabs with Ctrl+W, wait a minute, note again.
   Look for: does each tab add threads, and do they go away?
