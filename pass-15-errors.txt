VM CHECK (Windows 11; the Win32 sentences and "Unspecified error" are from Microsoft's System Error Codes and COM Error Codes pages; nothing below is):
1. Location is not available: in File Explorer, make a folder, remove your own permissions on it (Properties > Security > Advanced > Disable inheritance > Remove all), then open it from its parent.
   Look for: the title, the icon (red X or other), the text ("C:\Users\you\Private is not accessible." blank line "Access is denied."), the buttons (OK only?), and whether there is any Details or See details expander.
2. Rename refused: in a folder where you may not write (for example C:\Program Files\Common Files as a standard user), select a file, press F2, type a new name and press Enter.
   Look for: the dialog's title ("File Access Denied"?), its heading ("You need permission to perform this action"?), whether it shows the file's icon, name, type, size and date, the buttons (Try Again, Cancel? Continue with a shield?), and, after Cancel, whether the name box stays open with the typed name or closes with the old name.
3. Rename unexpected error: rename a file on a USB stick while pulling the stick (or rename to a name that is too long for a deep folder).
   Look for: whether Windows says "An unexpected error is keeping you from renaming the file. If you continue to receive this error, you can use the error code to search for help with this problem." with an "Error 0x8007....: ..." line, and its buttons.
4. Missing share: type \\<a real PC>\NoSuchShare.
   Look for: the error code and words under See details (0x80070043 "The network name cannot be found."?).
5. Server gone while browsing: open a share on another PC, turn that PC's sharing off (or pull its cable), then press F5.
   Look for: what is shown (dialog or page) and the error code and words (0x80070040 "The specified network name is no longer available."? 0x8007003B?).
6. Wrong password: open \\<PC>\<share> that asks for a password, type a wrong one.
   Look for: the red line in the Windows Security dialog ("The user name or password is incorrect."?).
7. Damaged ZIP: make a copy of a .zip file, cut it in half (for example with PowerShell: $b=[IO.File]::ReadAllBytes('a.zip'); [IO.File]::WriteAllBytes('b.zip',$b[0..($b.Length/2)])), then double-click it.
   Look for: the title ("Compressed (zipped) Folders Error"?), the text ("Windows cannot open the folder." and "The Compressed (zipped) Folder 'C:\...\b.zip' is invalid."?) and where it shows (a dialog, or inside the folder view).
8. ZIP with an unsupported method: a ZIP made by 7-Zip with the PPMd or LZMA method; double-click it and open a file inside.
   Look for: the message Windows shows.
9. Format failure: format a USB stick that a program holds open (open a file on it in Notepad), or one with a damaged partition.
   Look for: "Windows was unable to complete the format." and its title and button.
10. New folder where you may not write: in C:\Program Files as a standard user, right-click > New > Folder.
   Look for: the title ("Destination Folder Access Denied"?), the text, and the buttons (Continue with a shield, Skip, Cancel?). OpenXplorer still shows this in the message line.
