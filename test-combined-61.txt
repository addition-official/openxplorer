CHANGES (everything since deb 60, in plain words):
From the owner (upstream 2.0.26):
- Dark desktops beyond GNOME (#395): the System theme now follows a dark KDE Plasma, Cinnamon, COSMIC, Xfce or MATE desktop. It reads GNOME's color-scheme first, then the desktop portal's color scheme (which KDE, Cinnamon and COSMIC set), then any GTK theme name with "dark" in it (which Xfce and MATE set), and follows changes.
- The desktop's own terminal (#430): Open in Terminal, scripts run from a drop and Open with's custom commands now know Ptyxis, Ghostty, Alacritty, WezTerm, foot, Tilix and Terminator, and open the terminal the desktop is set to use. A terminal named in xdg-terminals.list that the app cannot start itself opens through xdg-terminal-exec, which is also the last resort when no known terminal is installed.
- Single click opens items (#429): Folder Options > General > "Click items as follows" now works. With single-click, a plain click on an item's icon or name opens it in every view; resting the pointer on an item selects it (Ctrl adds, Shift extends); the pointer is a hand over items, and names are underlined always or only when pointed at. Ctrl, Shift and Alt clicks, check boxes, arrows, rubber bands and drags work as before. Saved as preferences only when they differ from Windows' default.
- Release 2.0.26 (#431) and two test fixes for slower distribution build machines (#432, #433, the photo decoder memory test).
- Upstream also took our 32 PRs; the tree keeps our newer versions of them.
From our branches:
- Classic menu check marks (pass-14-menu-check): a checked item in a classic menu draws Windows' small Win32 check.
- Compact menu strip (pass-10-recent-strip): the strip's buttons now sit 65 pixels apart, as measured on Windows 11.
- Home like Windows 11 (home-like-windows-2): Home's command bar gets "Filter", to list only some kinds of files in Recent and Favorites (All File Types, Documents-type choices such as PDF, Presentations, Spreadsheets), Windows 11's "..." menu (a new setting, off by default, adds "Select items matching..." back to it), and a heading pill; tiles sized as Windows 11 sets them; Sort grayed on Home; the menu's edge as Windows draws it.
- Navigation pane as a tree (pass-4-tree-expand): drives, shares and folders in the navigation pane expand as a tree. A row's tooltip shows only when its name is cut short. Tooltips are kept to where Windows 11 has them: the Details button says "Show or hide the details pane.", Paste says "Paste (Ctrl+V)", the caption buttons say "Restore Down" and "Close"; the pane's resize handle, the folder tree's rows, the search box and Settings' Back button no longer show tooltips. Hidden expand arrows show from the pane's own pointer tracking.
- Details rows (details-row-end): a selected row's right end is drawn whole and rounded like its left, with Windows' corners and the gap before the focus ring.
- This PC look (this-pc-look): group headers, the capacity bar and tiles drawn as in Windows 11.
- Command bar and menu glyphs (icons-command-bar): the View button shows the view on screen (Large icons as Windows' monitor), pins are filled, command and menu glyphs are two-tone as in Windows 11, Filter gets its funnel; a symbol font that cannot be read now says why.
- Address bar root (pass-5-root-icon): the start of the address bar's chain shows the location's root as its first icon (Network as Windows' globe with a monitor), kept monochrome with icon files on; Windows' places are listed as text under the root chevron; no tooltip or history button; typed addresses show while typing; Windows' 499-pixel search box behind a divider it remembers; the search box's clear X where Windows 11 draws it.
- Gallery without flashing (gallery-no-flash): Gallery lays its photos out once as it opens, with the heading's row from the start, shows the photos read within 300 ms, and keeps rows on screen still as more come.
