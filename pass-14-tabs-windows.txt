VM CHECK
Check these in the Windows 11 VM's File Explorer (24H2 or later, with tabs). Turn on Folder Options > View > "Restore previous folder windows at logon" for 1.

1. Restoring several windows
   Steps: Open two File Explorer windows, give each two or three tabs in different folders, sign out, sign in.
   Look for: both windows come back with all their tabs and the tab that was in front in each; which window ends up in front. The branch reopens every window, the one used last in front.

2. Keyboard after Ctrl+T
   Steps: Click the Refresh button, then press Ctrl+T, then press Down.
   Look for: whether Down moves the selection in the new tab's Home list, or moves focus to another control. The branch selects the first item.

3. Keyboard after another app opens a folder
   Steps: With File Explorer open, click the desktop or another app, then press Win+R, run "explorer C:\Windows", then press Down.
   Look for: whether it opens a tab or a window (build dependent), and whether Down moves in the file list. The branch opens a tab and Down selects the first item.

4. Dragging files over the tab row
   Steps: Drag a file from the file list over another tab and hold it there.
   Look for: what is highlighted (only that tab, or the whole tab row) and after how long the tab comes to the front.

5. The tab of a drive
   Steps: Open C:\ and a USB stick's root, each in a tab.
   Look for: the tab icon (drive or folder) and the address bar icon, and the tab title ("Local Disk (C:)"). The branch shows the drive icon, titled "Local Disk" for /.

6. The tab of a ZIP folder
   Steps: With "File name extensions" off, open a .zip file as a folder in a tab.
   Look for: whether the tab, the address bar and "Search ..." say "Name" or "Name.zip". The branch says "Name.zip" everywhere while the file list says "Name".

7. Where new tabs go
   Steps: With three tabs, select the first; middle-click a folder; then press Ctrl+T.
   Look for: whether the middle-clicked folder's tab goes right after the current tab or to the end, and where the Ctrl+T tab goes. The branch: middle-click right after the current tab, Ctrl+T at the end.

8. Double-click on a tab
   Steps: Double-click a tab that is not in front, then one that is.
   Look for: whether anything happens (a copy of the tab, maximize, nothing). The branch duplicates the tab (Dolphin's behavior, kept by the owner).

9. A tab dragged out of the window
   Steps: Drag a tab down out of the window and let go.
   Look for: where the new window appears (under the pointer?) and its size.

10. Back in a window opened from Run
   Steps: Win+R, "explorer C:\Windows" with no Explorer window open.
   Look for: whether Back is enabled in the new window. The branch's window opened from the command line has Back enabled (to Home); left for the startup pass.
