VM CHECK (Windows 11 File Explorer; none of these was confirmed from a Microsoft source):
1. Quoted path. Click the address bar, type "C:\Windows\System32" WITH the double quotes, press Enter. Look for: it opens System32 (ours: opens the path). Also try "Recycle Bin" in quotes.
2. Environment variables. Type %USERPROFILE%\Music, then %userprofile%\Music (lower case), then %NOT_SET%\Music, each + Enter. Look for: the first two open Music; the third shows the "Windows can't find '%NOT_SET%\Music'" box (exact words, and whether the text in the box is the typed text or an expanded one). Also note whether $HOME or ${HOME} does anything (ours expands them; Windows probably does not).
3. Tab in the suggestions. Type C:\Pro and wait for the drop-down. Press Tab, Tab again, then Shift+Tab. Look for: does Tab put "C:\Program Files" into the address and the next Tab "C:\Program Files (x86)" (ours: yes, and Shift+Tab goes back), or does Tab leave the address bar? Does the list stay open?
4. Typed history across windows. Type C:\Windows + Enter and C:\Users + Enter in one window. Press Ctrl+N, then F4 (or the chevron at the address bar's right end) in the new window. Look for: both listed, newest first. Then restart Explorer (Task Manager > Windows Explorer > Restart) or sign out and in, press F4 again: still listed? Count how many entries the list keeps at most (ours 20). Then Folder Options > General > Clear: is the F4 list empty?
5. Typed history while typing. With a few typed paths kept, click the address bar and type just "C:\U" (or "C"). Look for: does the drop-down list earlier typed addresses that start with the text, besides folder names? (Ours lists folder names only while typing.)
6. Dragging a crumb. Open Music, drag the "Music" crumb in the address bar onto Desktop in the navigation pane, and read the label under the pointer before releasing. Look for: "Move to Desktop", "Copy to Desktop" or "Create link in Desktop"; then the same with Ctrl held. (Ours: Move, and Copy with Ctrl.) Undo afterwards with Ctrl+Z.
7. Ctrl+click and Shift+click on a crumb. Look for: does Ctrl+click open the folder in a new tab (in front or behind?) and Shift+click in a new window? (Ours: Ctrl background tab, Ctrl+Shift front tab, Shift new window.)
8. Right-click on a crumb. Write down every item of the menu in order (for example Copy address, Copy address as text, Edit address, Delete history, Open in new tab). Ours: Copy address, Paste and go, Open "<folder>" in new tab, Open "<folder>" in new window, Edit address, Keep address editable, Show full path.
9. The « overflow. Open a deep folder (8+ levels), make the window narrow until « appears, click it. Look for: the order of the hidden folders (nearest first or last) and what follows the divider (ours: hidden folders from the top of the path down, then Home, This PC, Network, Recycle Bin).
10. Back list. Visit five folders, right-click Back. Look for: how many entries, nearest first, and whether the current folder is listed (ours: up to 12, nearest first, current not listed). Same for Forward after going back twice.
11. Stop on a slow network folder. Type \\<a host that does not answer>\share, press Enter, then press Stop (X) while "Working on it..." shows. Look for: what the list says afterwards (empty, "This folder is empty.", or the previous folder) and where the address bar points.
12. Typed names. From C:\Windows type Documents, Downloads and Desktop (each + Enter). Look for: do they open the user's folders or say "can't find"? (Ours opens Desktop/Documents only as folders relative to the current one.)
13. shell: folders. Type shell:downloads + Enter. Look for: opens Downloads (ours: "can't find"; not added in this pass).
14. A typed file path. Type C:\Windows\win.ini + Enter. Look for: it opens in Notepad, and whether it then appears in the F4 list.
