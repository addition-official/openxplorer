# Title

fix(files): Show names, sizes and the command bar as Windows 11 File Explorer does

# Body

Model: claude-opus-5-5

## What changes

1. **Hidden extensions for every known type.** With "Hide extensions for known file types" on, `sunset.png`, `data.json`, `page.html` and `script.py` kept their extensions because GIO calls those types "uncertain" (several types share the extension). Any extension GIO names a type for now counts as known, as the Open and Save dialog already read it. Only the last extension is hidden (`Bundle.tar.gz` shows as `Bundle.tar`); an extension of digits alone (`Notes v2.1`) stays part of the name.
2. **One size per file outside the Size column.** The Details pane and the item tooltip now use the status bar's formatter (`4.38 KB` for 4,486 bytes in all three, as in Tiles and Content). The Size column keeps whole kilobytes rounded up (`5 KB`). One byte reads `1 byte`. Source for the decimal format: Microsoft's `StrFormatByteSize` examples (https://learn.microsoft.com/en-us/windows/win32/api/shlwapi/nf-shlwapi-strformatbytesizew: 1340 -> "1.30 KB", 23506 -> "22.9 KB"). That Explorer's pane, status bar and tooltip use exactly this format is not stated by Microsoft.
3. **Size column width.** The default Size width is 130 px (was 90), enough for ten digits of kilobytes (`9,999,999,999 KB`), so a 6 GB file's `6,291,456 KB` is no longer cut. The 70 px minimum is unchanged.
4. **Odd names.** Files whose names hold a line break or bytes that are not UTF-8 can be renamed, copied and moved to the Recycle Bin. The "Encoded control characters" and UTF-8 checks now apply to typed addresses; an existing item's URI keeps its exact bytes once its server, share or device part is checked and its path is absolute and normal. The snapshot write guard checks such items the same way. **Deliberate exception:** the clipboard keeps the safety rule that no payload carries an escaped control character (CLIP-005, SAFE-010), so a file whose name holds a line break cannot be copied with Ctrl+C; it can still be renamed, moved to the Recycle Bin and copied by other means. A name that is not UTF-8 can be copied with Ctrl+C.
5. **Trailing periods and spaces.** Renaming in place, the Rename dialog, New folder and the New menu's files trim periods and spaces at the end of a typed name ("Archive." and "Archive. " become "Archive"). Microsoft: "Do not end a file or directory name with a space or a period. Although the underlying file system may support such names, the Windows shell and user interface does not." (https://learn.microsoft.com/en-us/windows/win32/fileio/naming-a-file). "Notes .txt" is unchanged, and a name of periods only ("...") is kept as before.
6. **Erased name keeps the old name.** Erasing the whole name in place and pressing Enter closes the field and keeps the old name, with no message and no Undo entry, in Details, Tiles, Content and the Open and Save dialog. This is the user's decision after checking Windows 11; no Microsoft page was found for it. The Rename dialog still refuses an empty name.
7. **"…" is named See more.** The command bar's "…" tooltip and accessible name are "See more". Microsoft's File Explorer page says "select **See more** > **Options**" (https://support.microsoft.com/en-us/windows/experience/fileexplorer/file-explorer-in-windows); the page shows the button as an icon and does not call it "…" in words.
8. **Alt alone.** Pressing and releasing Alt with nothing between moves the keyboard to the command bar's first button with its focus ring; Escape gives it back. Alt with another key (Alt+Left, Alt+D, ...) is only that shortcut. Microsoft (Windows 11): "To move the focus to the app bar buttons: Press the Alt key." (https://support.microsoft.com/en-us/windows/use-a-screen-reader-to-explore-and-navigate-file-explorer-in-windows-e7d3a548-87dd-459f-a991-9fde3f7ce927). Escape returning the keyboard is not stated there.
9. **About says Linux** (separate commits): Settings > About and About this build say "An independent Windows 11–inspired file manager for Linux." instead of "for Zorin.".
10. **One spelling of license** (separate commits): the About page's lead line and the manual say "license", as the "License & source" heading does. Settings search still finds "licence".

Also: a Replace merge now replaces a file whose name is not UTF-8 (it used to stop there), and the parity notes, the guide (See more) and ui-spec follow the changes. Translations: the template is regenerated; zh_CN keeps its existing translations, moved to the new plural "{bytes} byte" entry and the edited About strings. "See more" has no Chinese translation yet (machine translations are not accepted).
