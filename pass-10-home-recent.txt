VM CHECK
Use File Explorer's Home in the Windows 11 VM, with a few recently opened files. None of these is on a Microsoft page.

1. Remove from Recent
   Steps: Home > Recent, right-click a file.
   Look for: the exact wording ("Remove from Recent"?), which icons are in the top strip (this branch: Cut, Copy, Rename, Delete; is Share there?), and the order of the other rows. After choosing it, the file should stay on disk and leave the list.

2. Delete and Rename from Recent
   Steps: Home > Recent, click a file, press Delete; on another file press F2.
   Look for: Delete moves the real file to the Recycle Bin and the row disappears (this branch does that). F2: does Windows rename in place in the row? (this branch opens the Rename dialog). After a rename, is the file still in Recent under its new name? (this branch: yes, and in Favorites too).

3. Command bar on Home
   Steps: Home > Recent, click a file, look at the command bar; click blank space.
   Look for: Cut, Copy, Rename, Share, Delete enabled with the row selected, grayed out after the click on blank space (this branch: same, without Share).

4. A recent file deleted elsewhere
   Steps: Open a .txt from Documents in Notepad, close it, delete it in another Explorer window, go back to Home (no F5).
   Look for: whether the row is still listed, and what opening it says. This branch keeps the row until Home is drawn again or the file is opened ("Item Not Found"), then drops it.

5. Reordering Quick access tiles
   Steps: Home, drag the Pictures tile onto the right half of the Downloads tile.
   Look for: whether Windows reorders the tiles (and the navigation pane) and draws an insertion mark while dragging. This branch reorders both, without a mark.

6. Favorites order
   Steps: Add three files to Favorites one after another (right-click > Add to favorites), open Home > Favorites.
   Look for: newest first or oldest first. This branch lists them in the order added, oldest first.

7. How many files Recent shows
   Steps: Open 30 or more different files, then look at Home > Recent.
   Look for: how many rows Windows lists (this branch: up to 50), and whether any Today / Yesterday / Earlier headings appear (this branch: none).

8. Classic menu near the bottom
   Steps: Make the window short, right-click the last Recent row > Show more options.
   Look for: whether the classic menu opens upward to fit. This branch's runs off the bottom of the screen.
