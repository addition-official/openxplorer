VM CHECK
Windows 11 behaviors this pass couldn't confirm from a Microsoft source. Try each in the Windows 11 VM's File Explorer and compare.

1. Pin from a menu goes last
   Steps: Right-click any folder in the file list > Pin to Quick access.
   Look for: it appears at the bottom of the pinned folders, below Videos (or below the last pin). This pass made OpenXplorer do that.

2. A file dragged near a pin's edge
   Steps: Drag a .pdf from Documents onto the very top edge of the pinned "Downloads" row, where a folder would show the insertion line.
   Look for: whether Windows shows an insertion line or "Move to Downloads" with the whole row highlighted, and where the file ends up. This pass made OpenXplorer move it into Downloads.

3. Dragging the pane's edge
   Steps: Drag the border between the navigation pane and the files to make the pane about 1.5 times as wide. Close Explorer and open it again.
   Look for: the width is kept. Then drag the border fully left: does the pane collapse to nothing, or stop at a minimum width (OpenXplorer stops at about 120 px)?

4. Ejecting a drive that's in use
   Steps: Plug in a USB stick. Open a file from it in Notepad and keep it open. In Explorer, show the stick's root, then right-click the stick in the navigation pane > Eject.
   Look for: the exact title and text of the message (OpenXplorer now says "This device is currently in use. Close any programs or windows that might be using the device, and then try again."), and whether the Explorer window stays on the stick or moves away.

5. Ejecting a drive that's free
   Steps: Close Notepad, show the stick's root in Explorer, then Eject from the navigation pane.
   Look for: where the Explorer window goes (This PC, closes, or stays with an error). OpenXplorer goes to This PC.

6. Double-click in the navigation pane
   Steps: Double-click "This PC". Then double-click a pinned folder that has subfolders.
   Look for: whether each double-click collapses or expands the node, or only opens it. This pass made OpenXplorer toggle This PC, Network and folder-tree folders.

7. Expand to open folder and Show all folders
   Steps: Right-click empty space at the bottom of the navigation pane.
   Look for: whether "Show all folders" and "Expand to open folder" are listed, whether "Expand to open folder" is on or off by default (also in Folder Options > View > Navigation pane), and what turning it on does when you open Documents\some subfolder from the address bar.

8. Arrow keys in the navigation pane
   Steps: Click "Home" in the navigation pane, then press Down a few times.
   Look for: whether keyboard focus stays in the navigation pane after the click, and whether each arrow press opens that folder in the file list (after a short pause) or only moves the focus. OpenXplorer moves focus to the files after a click, and arrows only move focus.

9. Keypad and main keyboard plus/minus
   Steps: Select "This PC" in the navigation pane. Press the main keyboard's "-" and "+" (not the keypad), then the keypad's "-", "+" and "*".
   Look for: which keys collapse and expand. OpenXplorer uses only the keypad keys.

10. Home and Gallery menus
   Steps: Right-click Home, then Gallery, in the navigation pane.
   Look for: the exact items and their order. This pass added "Open in new tab" and "Open in new window" to OpenXplorer's.

11. Unpin message
   Steps: Right-click a pinned folder > Unpin from Quick access.
   Look for: whether any message appears. OpenXplorer shows "Unpinned. The folder was not deleted.", which the owner chose to keep for now.

12. A pinned folder that was deleted
   Steps: Pin a new folder, delete it in the file list, then click its pin.
   Look for: whether Windows removes the pin, shows a dialog (and its wording), or shows an in-window message. OpenXplorer keeps the pin and shows "This location is unavailable" in the window.

13. Screen reader names
   Steps: Turn on Narrator (Ctrl+Win+Enter), Tab into the navigation pane and arrow over a pinned folder, This PC and a drive.
   Look for: what Narrator says for each, for example whether it says "pinned", "collapsed or expanded" and the tree level.
