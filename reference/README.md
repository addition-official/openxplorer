# Windows 11 reference screenshots

Captured on 2026-11-22 from the Windows 11 VM's own framebuffer at 1920x1080, 100% scale, in the dark theme. File name extensions are shown. They are the exact pixels, not scaled.

The test folder is C:\Users\aaa\Documents\RefTest. It holds the folders Music, Photos and Projects, plus the files Archive.zip, "Budget 2026.xlsx", a 108-character .jpg name, "Invoice 1042.pdf", "Meeting notes.txt" and "Report final.docx".

Every UI job compares its own capture of the same screen, made the same way (1920x1080, 1x, dark, same files), against these. Measure with a script, not by eye: icon boxes, glyph sizes, row heights, paddings, text positions and where text is cut with "...". Report the measured numbers for both.
